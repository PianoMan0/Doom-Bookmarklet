# Doom Bookmarklet
Doom running in a bookmarklet!

## How to use
1. Open `doom-bookmarklet-minified.js` and copy the full code.
2. Create a new bookmark in your browser.
3. Set the URL/location of the bookmark to the pasted `javascript:` line.
4. Click the bookmark on any page to launch DOOM!

<br>
Don't have a browser that can run bookmarklets?

Check out https://hacklet.hackclub.com/preview.html?id=local-msjf32aq-x743xh2fovn

## What is a bookmarklet?
A is a small JavaScript program stored as a browser bookmark. When clicked, it runs code to modify a webpage, extract data, or perform quick actions. 

## Controls (default for DOOM)
- Arrow keys / WASD : move
- Ctrl : fire
- Space : open / use
- Shift : run
- 1-7 : select weapon
- Alt : strafe (hold)
- Esc : pause menu
